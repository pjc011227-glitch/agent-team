使用说明

① 在服务器上运行 Agent Team（必须配置所有者口令、HTTPS 或 VPN）；② 为电脑创建设备，保存一次性设备密钥；③ 在电脑安装项目并启动 agent-team-worker；④ 在此页面选择设备发送任务。

本版本提供的是受限任务代理，不是任意远程 Shell，也不能操纵桌面窗口。真正的 GUI 自动化需本机权限审批和独立插件。
