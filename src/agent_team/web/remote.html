使用说明

① 在服务器上运行 Agent Team（必须配置所有者口令、HTTPS 或 VPN）；② 为电脑创建设备，保存一次性设备密钥；③ 在电脑安装项目并启动 agent-team-worker；④ 在此页面选择设备发送任务。

智能体只会解析固定的少量自然语言模板，无法执行任意自然语言任务；远程 Shell 和桌面窗口控制尚未实现。运行测试会执行本机项目代码，仅适用于你信任的项目，并需要电脑端启动参数授权。真正的 GUI 自动化需本机权限审批和独立插件。
