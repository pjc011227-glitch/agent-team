# 开发路线图

### v0.2：跨端 PWA 聊天原型（完成）

- [x] 同一套桌面/手机 UI、基础 PWA Manifest
- [x] 独立 Agent 的创建、编辑、备注、头像和模型分配
- [x] SQLite 会话及聊天历史
- [x] 私聊、@群聊、圆桌、有限接力协作
- [x] 不同/共用 API Key 的凭据抽象，服务端加密
- [x] OpenAI-compatible、Anthropic、Gemini 模型适配器和演示模式
- [x] Prompt Skills 管理与 Agent 分配
- [x] 15 项离线自动化测试

### v0.3.3：远程任务链路（基础版已完成）

- [x] 手机与桌面端访问同一服务器及会话数据库，聊天页定时同步
- [x] 设备注册、一次性密钥、心跳、撤销及白名单任务队列
- [x] Windows/Linux 电脑端 Python Worker 主动领取任务并回传结果
- [x] 手机设备列表与任务面板、受控目录的列目录与便签写入
- [x] 任务超时标记为中断、取消排队任务、手动重新派发，禁止中断自动重复执行
- [x] 设备任务状态筛选、进度标签和结果回显
- [x] 工作目录纯文本读取、符号链接和隐藏路径隔离测试
- [x] Docker 容器配置、默认仅监听宿主机回环、非 root 运行、部署指南和构建 CI
- [ ] 真正可续租的长时任务、审批界面、任务日志、设备令牌轮换和云端安全加固
- [ ] 实际桌面自动化/应用交互（必须有单机逐项授权与撤销）

### v0.4：日常使用体验

- [ ] SSE 流式输出、停止生成、消息重发与编辑
- [ ] 群组成员增删、排序、发言 @ 自动补全
- [ ] 接入模型列表、模型能力标记、调用耗时与用量统计
- [x] 基础 Docker Compose 部署配置和 HTTPS 反代教程（反代仍需用户部署）
- [ ] 正式的 HTTPS 部署演练、端到端测试和服务端限流
- [ ] 图片、文件、代码块、Markdown 格式

### v0.5：原生双端（Windows / Linux + Android）

- [ ] 评估并集成 Tauri 2，把 Web UI 打包成安装程序和 APK
- [ ] 原生安全存储、后台运行策略、操作系统通知
- [ ] 桌面连接本地服务/远程服务的部署模式
- [ ] Android 连接同一服务器的登录与配对流程
- [ ] GitHub Actions 跨平台发布构建

### v0.6：真正的智能体协作

- [ ] Supervisor/Planner/Reviewer 模式（可选，不强制所有聊天都走主管）
- [ ] 多 Agent 任务图、有预算和上下文约束的循环
- [ ] 协作任务状态、取消/恢复、审批/审查、统一事件审计
- [ ] 多模型成本策略、降级与限额

### v0.7：插件平台与官方授权登录

- [ ] 可执行 Skill / MCP Plugin：manifest、权限请求、沙箱与版本管理

- [ ] 逐供应商接入官方 OAuth/授权方式（只做提供商实际支持的能力）
- [ ] 多用户授权、端到端同步、安全备份恢复
