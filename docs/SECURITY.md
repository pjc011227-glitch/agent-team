# 安全原则

1. **本地优先**：默认仅监听 `127.0.0.1:8765`。非 localhost 监听要求 `AGENT_TEAM_ACCESS_TOKEN`；只设置口令不等于具备公网生产级安全，跨网络必须添加 HTTPS / VPN。
2. **密钥最小暴露**：密钥在服务器本地使用 Fernet 对称加密；`encryption.key` 与 SQLite 存于用户私有目录。需保护整个目录并避免将两个文件一并泄露。设置文件加密不代表防御拥有本机同等访问权限的恶意程序。
3. **不在客户端缓存 API Key**：浏览器只接收凭据元数据，模型请求由服务端完成。
4. **暂不提供任意工具运行**：外部 Skill 不会获得 Shell/文件系统权限；可执行 Plugin 接入前必须定义权限和人工审批流程。
5. **不支持绕过平台登录**：不能以网页 Session Cookie 冒充官方 OAuth，也不能将订阅额度冒充 API 额度。
6. **防止高费用自动循环**：单次发送最多 4 位 Agent 各调用 1 次，无无限循环；但仍应在账户侧设置用量额度。
7. **保密意识**：聊天内容会发送到所选模型接口，敏感数据不要无意识分享给不同服务商。

## 远程任务执行（v0.3）

远程设备令牌仅能访问 heartbeat/领取任务/回传结果，不能用于所有者 API、模型凭据或其他设备。令牌在服务端只存 SHA-256 哈希；设备撤销后失效。远程控制 API 要求服务器配置所有者口令；电脑 Worker 只接受 HTTPS（或本机测试 HTTP）。命令执行与通用鼠标键盘权限尚未实现。详情见 [远程执行设计](REMOTE_CONTROL.md)。


## v0.4 受限自然语言任务与测试执行

自然语言只用于生成待确认的白名单任务预览，不向未授权设备派发，也不会直接运行未知命令。`search_text` 只读用户明确授权的根目录内常用小文本文件，隐藏路径和符号链接被跳过。`run_tests` 需要电脑上的 `--allow-tests` 本地开关，运行固定 unittest 命令，但**测试文件本身是可执行 Python 代码**，仅允许可信项目使用；将来需 OS 级沙箱、资源限制和独立审批才可安全扩展。
