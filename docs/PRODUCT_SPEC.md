# Agent Team · 产品规格（v0.3.1）

## 核心愿景

聊天软件式的多智能体工作台。智能体像通讯录中的人，有名字、备注、头像、身份和能力。用户与其自然聊天，或把多个智能体组织成有分工的群组共同完成问题。Windows、Linux、Android 视觉与业务逻辑一致，同一个服务端可以同步消息。

## 产品行为

- 私聊始终由单个 Agent 回复，能够单独设置模型与人格。
- 群聊三种模式：@点名、圆桌讨论、协作接力；非 @ 场景下默认仅首个成员答复，以避免意外费用。
- @点名优先于群聊默认模式；连续 @多名最多触发 4 人，不运行无限链条。
- 群组中智能体在同一会话里共享消息上下文，但各自拥有自己的系统角色、模型与所授权的文本 Skill。
- 无配置时只运行演示模式，不能假装生成了真实答案。
- 不允许直接使用浏览器 Cookie、网页订阅、抓包方式伪造厂商授权登录。

## 后续交互（优先级）

1. 聊天列表搜索、群聊成员增删、会话编辑、逐条消息重试。
2. 流式输出、消息 Markdown/代码块、附件与拖拽、模型列表自动拉取。
3. Agent 对 Agent 私信、房间身份和真实角色分工、管理员审批、暂停/继续。
4. 可配置工作流、显式预算上限、可追踪执行图、并行/异步协作。
5. 安全插件系统（权限清单、工具调用确认、审计、安装来源检查）。
6. 官方授权账号登录（逐个厂商接入），而非通用的账户密码输入框。
7. 原生通知、系统托盘、文件分享、跨端安装包与可靠的自动更新。
